🔍 Environment Variables Checker

Purpose: This page helps you verify if your React app is correctly loading environment variables from the .env file.
📋 Instructions:

1. Start your React development server:

cd frontend
npm run dev

2. Open the browser console (F12) in your React app

3. Run this command in the console:

console.log('API Key:', import.meta.env.VITE_GOOGLE_MAPS_API_KEY)

4. Check the output:

✅ Expected Output:
API Key: AIzaSyB2Mo8gdkO3-35tsmrf_WlBrSkTbUKYp9Q

If you see the full API key, environment variables are loading correctly! ✨

❌ Problem Scenarios:

If you see: API Key: undefined

Your .env file is not being read. Solutions:

  1. Make sure frontend/.env file exists
  2. Verify the file contains: VITE_GOOGLE_MAPS_API_KEY=AIzaSyB2Mo8gdkO3-35tsmrf_WlBrSkTbUKYp9Q
  3. RESTART the dev server (Vite only reads .env on startup)
  4. Check that there are no extra spaces or quotes around the value

If you see a different/old API key:

Your .env file is outdated. Update it and restart the dev server.

🔧 Common Fixes:

1. Environment variables not loading?

  • Stop the dev server (Ctrl+C)
  • Check frontend/.env file exists and has correct content
  • Restart: npm run dev

2. Map still blank after env vars are correct?

  • Check if there's actual data with coordinates in the session
  • Open browser DevTools console and look for errors
  • The map needs at least one place with valid latitude/longitude

3. Still having issues?

  • Clear browser cache and hard reload (Ctrl+Shift+R)
  • Try in incognito/private browsing mode
  • Check the Network tab in DevTools for failed requests
📝 Debug Checklist:
□ .env file exists in frontend/ directory
□ VITE_GOOGLE_MAPS_API_KEY is set in .env
□ Dev server was restarted after .env changes
□ Console shows correct API key value
□ Browser console has no red errors
□ MapView component is receiving data with coordinates
□ Network tab shows Google Maps API loading successfully
